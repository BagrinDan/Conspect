    public Map<Character, Integer> charCount(char[] arr){
        Map<Character, Integer> map = new HashMap<>();

        char[] tolow = arr.toLowerCase();
        tolow.replaceAll(String.valueOf((char) 0), "");

        for (int i = 0; i < tolow.length; i++) {
            map.put(tolow[i], map.getOrDefault(tolow[i], 0) + 1);
        }

        return map;
    }

Q4:
    
    class node{
        public int data;
        public Node next;

        public node(int new_data){
            this.data = new_data;
            this.next = null;
        }
    }

    public node reverseList(node head){
        node current = head;
        node prev = null;

        while(current != null){
            next = current.next;

            current.next = prev;

            prev = current;
            current = next;
        }
        return prev;
    }

    public List<String> groupAnnograms(String[] strlist){
        HashMap<String, Integer> hash = new HashMap<>();


        for(String string : strlist){
            char[] arr = strlist.toCharArray();
            Arrays.sort(arr);
            String sorted = new String(arr);


            if (!hash.containsKey(sorted)) {
                hash.put(sorted, new ArrayList<>());
            }

            hash.get(sorted).add(string)
        }

        return new Arraylist<>(hash.values)
    }

Q14:
    1. A Primary Key is a unique attribute that identifies each record in a table.
       A Foreign Key is an attribute used to create a relationship between tables.  
    
    2. When we pass a value by reference, we pass a reference to the original object, so both variables refer to the same data. 
    If one object changes the value, the other will see the changes as well. 
    When we pass by value, a copy is created, so changes do not affect the original value

    3. NULL represents the absence of a value.
    It can be problematic because operations involving NULL may produce unexpected or undefined results. For example, comparing NULL = NULL does not return TRUE in SQL.
    Also, if important attributes contain NULL values when they should not, it may break the integrity of the database structure.
