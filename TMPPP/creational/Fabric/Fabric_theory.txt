===============================

[Creational] - Fabric Method

===============================

--Определения-- : Фабричный метод - это порождающий паттерн проектирования, 
который определяет интерфейс создания объекта, но позволяет субклассам выбрать 
класс создаваемого экземляра. Таким обзаром, Фабричный Метод делегирует операцию
создания экземпляра субклассам

--Основные понятия--

Product <<Interface>> - общий интерфейс для всех объектов, которые могут создавать фабрика

ConcreteProduct - Реализация интерфейса продукта 

Сreator <<Interface>> - класс, который объявляет фабричный метод. Он может содержать базовую 
логику, использующую продукты.

ContreteCreator

---------------------
-- Принципы SOLID --
---------------------

(Да)
S - Логика создания для каждого класса

O - Можно добавлять новые классы без модификации

L - Субклассы могут быть использованны вместо родительского

I - Простой интерфейс

D - Клиент зависит от абстракции, не от реализации


------------------
-- Плюсы/Минусы -- 
------------------

Плюсы: Легче поддержать, убирает new() из кода клиента[!], можно делать Мок тесты
 
Минусы: Растёт кол. классов, Overkill для простых систем, иерархия становится
более глубокой
