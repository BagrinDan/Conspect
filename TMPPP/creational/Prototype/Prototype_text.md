====================
[тип] Прототип
====================

===============
--Определения--
===============

    > Прототип - это пораждающий паттерн, который позволяет копировать объект не вдоваясь в его реализацию.

====================
--Основные понятия--
====================

    > Client

    > Prototype <<interface>> - родительский интерфейс

    > ConcretePrototy
    pe1,2 - класс который наследуется от интефрейса

========================
--Случаи использования--
========================
    - Когда нужно создать копию объекта, не привязываясь к его конкретной реализации (классу).
    - Когда создание объекта с нуля стандартным путем (через new) обходится слишком "дорого" для производительности.

==================
--Ключевые моменты
==================
    > DeepCopy -  копирует объект и если есть списки или вложенные объект - создает свой список или вложенный объект
        
        @Override
        public Student clone() {
            Address independentAddress =
                new Address(address.city);

            return new Student(name, independentAddress);
        }

    > Swallow-copy - копирует объект и если есть списки или вложенные объект - копирует только ссылку.
        
        public Student clone() {
            return new Student(name, address); // Копируем ссылку!
        }

==================
--Принципы Солид--
==================

    (ДА)
        > OCP - позволяет создавать новый Прототип не меняя основной класс Propotype
        > LSP - любой прототип может быть использован вместо интрфейса
        > DIP - Клиент работает с абстракцией

    (НЕТ)
        > SRP - ConretePrototype содержит и свою логику, и логику клонирования
        > ISP - если интерфейс не сегментировать, то он будет слишком жирным

================
--Плюсы Минусы--
================

    Плюсы: Производительность, упрощения создания объектов
    Минусы: Проблемы с DeepCopy,
