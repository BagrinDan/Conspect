====================
[тип] Адаптер
====================

===============
--Определения--
===============

    > Адаптер - это структурный паттерн, который позволяет объектам с несовместимыми интерфейсами работать вместе.

====================
--Основные понятия--
====================

    > Client - клиентский код который работает только с Target адаптации

    > Target<<inteface>> - класс с которым работает клиент. 

    > Adapter - класс переводчик, который помогает создать общение между объектами

    > Adaptee - класс который мы хотим адаптировать под новый интефрейс

========================
--Случаи использования--
========================
    - Когда легче адаптировать класс чем его переделать
    - Когда нужно использовать сторонний класс (библиотеку), но его интерфейс не соответствует вашему коду

==================
--Принципы Солид--
==================

    (Нарушает)
        > SRP - адаптер делает одну вещь
        > OCP - можно добавлять новые адаптеры
        > LSP - адаптер работает правильно в случае если клиент взаимодействует
            с таргетом
        > ISP - интерфейс как правило лаконичен
        > DIP - клиент работает с интерфейсом
    (Не Нарушает) 

================
--Плюсы Минусы--
================

    Плюсы:
        > Позволяет сэкономить время на рефакторинге создав адаптер
        > Не нарушает Солид
    
    Минусы:
        > Костыль
        > Усложнение кода
        > Падение производительности из-за еще однго класса в цепочке
