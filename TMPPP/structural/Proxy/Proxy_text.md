====================
[structural] Proxy
====================

===============
--Определения--
===============

    > Proxy - это структурный паттерн, который предоставляет объект заместитель, 
    управляющий доступом к другому объекту

=================
-- Особенности --
=================

    Есть 4 вида прокси:
        1. Remote proxy - выступает в роли локального представителя для объект,
            находящегося на другому сервере или в другом пространстве

        2. Virtual proxy - объект заместитель, который управляет доступом к "тяжелому"
            ресурсу, откладывая его создание или загрузку до момента первого фактического
            использования

        3. Security proxy - это посредник который ограничивает доступ к методам реального объекта
            на основе прав доступа, полномочии или других правил безопастности.

        4. Smart proxy - это объект который выполняет дополнительные вспомогательную действия
            при каждом обращении к реальному объекту 

====================
--Основные понятия--
====================

    1. Клиент - использует интерфейс Subject

    2. Subject (Interface) - предоставляет интерфейс Клиенту

    3. Proxy - через данный прокси взаимодействует или проходит реквест 

    4. Real Subject - сервис к которому обращается клиент
