====================
[тип] Состояние
====================

===============
--Определения--
===============

    > State (Состояние) — это поведенческий паттерн, который позволяет объекту изменять своё поведение 
    при изменении его внутреннего состояния. 

====================
--Основные понятия--
====================

    > Контекст - основной объект, поведение которого зависит от текущего состояния. Хранит ссылку на объект состояния (State).

    > Abstract State - интерфейс или абстрактный класс, который объявляет методы, общие для всех состояний

    > Contrete State - конкретная реализация состояния, определяющая поведение объекта в данном состоянии.

==================
--Принципы Солид--
==================

    (Не нарушает)
        > SRP - каждое состояние имеет свою ответсвенность
        > OCP - можно добавлять новые состояние без модификации кода
        > LSP - [ConcreteState] может заменить [AbstractState]
        > ISP - интерфейс [AbstractState] минималичен
        > DIP - [Context] работает через абстракцию

    (Нарушает)

================
--Плюсы Минусы--
================

    Плюсы:
        > Убирает большие if/switch по состояниям
        > Упрощает добавление новых состояний
        > Инкапсулирует поведение каждого состояния
        > Делает код более расширяемым

    Минусы:
        > Увеличивает количество классов
        > Может быть оверкиллом для простой логики состояний
        > Логика переходов между состояниями может стать сложной
