> DS -> Sintaxa, Semantica

> Date structurare - данные которые имеют строго определнный формат, 
организованных в виде таблиц со строками и столбцами
    * SQL, Excel

> Date semistructurare - данные которые не имеют жестко схемы, но содержат 
внутрение маркеры, теги или иерархию разделяющие данные и позволяющие парсить
    * JSON, XML

> Date nestructurate - данные без строгих правил структуры 
    * Фото, видео, txt

> avro - Основной упор сделан на работу с динамическими схемами и экосистемой больших данных (Big Data).
> thrift - По своей идеологии очень близок к Protocol Buffers.
> csv - для sql 
> json - rest api или если задействован java script
