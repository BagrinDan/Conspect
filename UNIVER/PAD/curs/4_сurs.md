**Thread-safe** - тип коллекции которые решают проблемы многопоточности

**Monolith** -  простая логика кода, но большая связаность
**Modular M** - всё в одном но разбито по модулям

**SOA** (server operational arhitecture) - одна общая БД 
**Micro-service** - по одной бд на каждый сервис 

**ESB** - программный маршрутизатор выступающий центральной точкой для всех приложении

**Мультиплексирование** — это одновременная передача множества независимых потоков данных через один общий физический или логический канал связи.
