Switch order boot:

    1. Switch loads a power-on self-test (POST) program stored in ROM.
    POST checks the CPU subsystem. It tests the CPU, DRAM, adn the portion of the flash
    device that makes up the flash file system.

    2. Next, switch loads the boot loader software. The boot loader is a small program stored
    in ROM that is run immediately after POST successfully copletes.

    3. The boot loader performs low-level CPU init. It init the CPU regist, which control
    where pysical memory is ampped the quantity of memory and its speed.

    4. The boot loaderd. initializes the flash file system on the system boar

    5. Finally, the boot loader locates and loads a default IOS operating system software image into
    memory and gives control of the switch over to the IOS


CiscoOS команды:

    > Режимы:
        enable [ИЛИ] ena - Привилегированный режим
        configure terminal [ИЛИ] conf t- превилигированный режим
    
    > Конфигурация:
        show running-config [ИЛИ] sh run -> посмотреть ВРЕМЕННУЮ конфигурацию (RAM).    
        show startup-config [ИЛИ] sh start -> посмотреть ПОСТОЯННУЮ конфигурацию (NVRAM)
        show flash - показать информацию про файловую систему флэш

        copy running-config startup-config - сохранить ВРЕМЕННУЮ конфигурацию в ПОСТОЯННУЮ 

    > Порты/Интерфейсы:
        show interfaces [interface id] - показать инфу о конкретном интерфейсе
        show ip/ipv6 interface - показать инфу об интерфейсах IP на layer 3-4
        show mac address-table - показать мак адресс 
        show interface - показывает инфу об интерфейсах на layer 1-2 

    > Прочее:
        show version - показать стостояние системы
        show history - показать историю команд

    > Диагностика:
        * show ip/ipv6 brief interface - Выводит компактный список всех сетевых интерфейсов устройства 
        с их IP-адресами (IPv4 или IPv6) и текущим статусом

        * show ip route - локальная вариация traceroute
            - L local: показывает айпи адрес устройства 
            - C connected: показывает к какой локальной сети мы подключены
            - S static: ручной прописаный маршрут.
            - R RIP (routing info prot): роутер каждый 30 сек обменивается своей таблицей маршурутизацией с 
            соседями. Позволяет лучше подобрать маршрут или обновить его
            - M Mobile IP: протокол для мобильных сетей 
            - B BGP (Border Gateway Protocol): соединяет роутер и провайдер

        * show running-config interface [интерфейс (g0/1)]- показать конфиг определённого интерфейса из RAM
        

    > Модификаторы: 
        - section: показывает определённую секцию
        - include (аналог grep)
        - exclude: (аналог grep -v) выводит всё кроме указаной строки
        - begin: выводит весь конфиг 
    
    > История команд: 
        - terminal history size 200: позволяет запомнить до 200 команд. Лимит 256 
        - show history: показавать историю команд 
        

Switch пример:
    > Настройка порта свича:
        enable ### Войти в root 
        сonfigure terminal ### Войти в превилигированный режим

        interface FastEthernet0/1 ### Войти в настройки интерфейса 
        duplex auto ### Ставим FULL_DUPLEX
        speed auto ### Скорость 100
        mdix auto ### Режим MDIX
        end ### Выходим из превилигированный режим 
        copy running-config startup-config ### Сохранить конфиг 

    > Настройка SSH:
        show ip ssh ### Позволяет понять если свич поддерживает ssh и какую версию поддреживает 
        ip domain-name cisco.name ### Задаём доменное имя необходимое для криптации
        crypto key generate rsa ### Генерим ассимитричные ключ RSA 
        username [login] secret [password] ### Создаем учетку админа

        line vty 0 15 ### Выбираем виртуальные терминальные линии 
        transport input ssh ### Включаем для них вход по ssh 
        login local ### ставим как логин названия switch 
        exit ### Выходим

        ip ssh version 2 ### Включаем вторую версию ssh

Switch режим:

    > SYST (System) - показывает общий статус систем/питания свича.
        * Зеленый: Система работает нормально.
        * Выключен: Система выключена.
        * Желтый: Ошибка системы или проблемы с питанием.

    > RPS (Redundant Power System) - статус внешнего резервного питания
        * Зеленый: Резервное питание подключено и готово к работе.
        * Мигающий зеленый: Подключено, но питает другой коммутатор в стеке.
        * Выключен: Резервный блок не подключен.
        * Желтый: В режиме ожидания или система неисправна.
        * Мерцающий желтый: Внутриние питание неисправно и
        RPS обеспечивает питание системы

    > STAT (Status) Режим отображения активности портов
        * Зеленый: Линк есть (устройство подключено).
        * Мигающий зеленый: Идет передача данных через порт.
        * Выключен: Кабель не подключен или порт выключен (shutdown).
    
    > DUPLX (Duplex) Режим отображения ружим дуплекса на портах
        * Зеленый: FULL_DUPLEX
        * Выключен: HALF_DUPLEX

    > SPEED: Режим отображения скорости рабоыт портов.
        * ВЫключен: 10 Мбит/с
        * Зеленый: 100 Мбитс/с 
        * Мигающий зеленый: 1000 Мбит/с 
    
    > PoE (Power over Ethernet) Режим отображения статус подачи питания 
        * Зеленый: Питание успешно подается га подключенное 
        * Мигающий зеленый/желтый: Ошибка подачи питания/превышен лимит мощности


> Auto-MDIX (Automatic Medium Dependent Interface Crossover) — это технология, 
которая позволяет сетевому порту коммутатора или сетевой карты автоматически определять 
тип подключенного кабеля (прямой или перекрестный) и корректировать назначение контактов на лету.
    * Используем кабель Crossover если устройства не поддерживают mdix 
    * Используем straight-through если устройства поддреживают mdix

    > Ingress (Входящий трафик) - обозначает интерфейс на которомы пришел пакет 
    > Egress (Выходящий трафик) - обозначает интерфейс с которого пришел пакет
