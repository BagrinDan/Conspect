

> STP - L2 протокол который помогает избегать зацикленой передачи
пакетов в сети

    > RSTP - Усовершенствованный стандарт STP, который снижает время перерасчета 
    топологии сети при авариях с 30–50 секунд до нескольких 
    миллисекунд / 1–2 секунд за счет механизма прямого рукопожатия (Proposal/Agreement) между коммутаторами.

    > PVST+ и Rapid PVST - Проприетарные протоколы Cisco, которые создают отдельный экземпляр STP 
    для каждого VLAN. Это позволяет балансировать трафик по разным физическим каналам. При этом PVST+ 
    работает со скоростью классического STP, а Rapid PVST+ использует алгоритмы RSTP для мгновенного переключения.

    > MSTP - Открытый стандарт, который объединяет группы VLAN в отдельные экземпляры (Instances) STP. 
    Он дает возможность балансировать трафик, как в PVST+, но не нагружает процессор коммутатора, 
    так как вместо сотен процессов STP создается всего 2–4 экземпляра для всей сети.


> Bridge Protocol Data Units (BPDUs) - тип данных который используется для 
передачи данных между свичами для настройки STP 


> Broadcast Storm - это проблема при которой происходит цекличная перессылка 
бродкаст пакетов между устройствами


> Port state:
    > STP: Disable, Blocking, Listening, Learning, Forwarding 
    > RSTP: Discarking, Learning, Forwarding 

> Port role:
    > STP: Root port, Designed Port, Blocket Port 
    > RSTP: Root port, Designed Port, Backup Port, Alternate Port
