=========================================
ШПАРГАЛКА ПО КОМАНДАМ CISCO IOS
=========================================

[ Режимы работы ]
    enable (или ena)             - Переход в привилегированный режим (Privileged EXEC)
    configure terminal (conf t)  - Переход в режим глобальной конфигурации
    end                          - Быстрый возврат в привилегированный режим из любого подрежима

[ Управление конфигурацией и памятью ]
    show running-config (sh run) - Просмотр текущей (временной) конфигурации в RAM
    show startup-config (sh start) - Просмотр сохраненной (постоянной) конфигурации в NVRAM
    copy running-config startup-config - Сохранение текущей конфигурации в постоянную память
    show flash                   - Информация о файловой системе флэш-памяти
    show version                 - Состояние системы, аптайм и версия ПО

[ Диагностика и мониторинг ]
    show ip interface brief      - Компактная сводка всех интерфейсов, IP-адресов и статусов (up/down)
    show interfaces [ID]         - Статистика конкретного интерфейса (L1-L2)
    show ip interface            - Параметры интерфейсов на сетевом/транспортном уровнях (L3-L4)
    show mac address-table       - Просмотр таблицы MAC-адресов коммутатора
    show ip route                - Просмотр таблицы маршрутизации:
                                > L (Local)     - локальный IP-адрес интерфейса
                                > C (Connected) - подключенная локальная сеть
                                > S (Static)    - заданный вручную маршрут
                                > R (RIP)       - маршрут по протоколу RIP
                                > M (Mobile)    - маршрут для мобильных сетей
                                > B (BGP)       - маршрут протокола граничного шлюза

[ Настройка безопасности и паролей ]
    service password-encryption  - Включает шифрование всех открытых паролей в конфиге
    enable secret [пароль]       - Задает надежный хэшированный пароль на привилегированный режим
    username [логин] secret [пароль] - Создает локальную учетную запись
    security passwords min-length 10 - Устанавливает минимальную длину пароля
    no ip domain-lookup          - Отключает попытки DNS-разрешения при опечатках

[ Удаленный доступ (SSH и VTY) ]
    show ip ssh                  - Проверка поддержки и версии SSH
    ip domain-name [домен]       - Задаём имя домена (обязательно для генерации RSA-ключей)
    crypto key generate rsa      - Генерация асимметричных ключей шифрования
    ip ssh version 2             - Принудительное включение безопасной версии SSHv2

    line vty 0 15                - Переход к настройке 16 виртуальных линий
        transport input ssh        - Разрешение подключений только по SSH
        login local                - Использование локальной базы пользователей (username)
    exit                       - Выход из настройки линии

[ Настройка интерфейсов и портов ]
    line con 0                   - Настройка консольного порта
        password [пароль]          - Установка пароля
    login                      - Включение проверки пароля при входе

    ip default-gateway [IP]      - Шлюз по умолчанию (для коммутатора Layer 2)

    interface FastEthernet 0/1   - Настройка порта коммутатора (L2)
        duplex auto/full/half               - Автоматическое определение дуплекса
        speed auto/10/100/1000             - Автоматическое определение скорости
        no/ mdix auto                  - Автоматическое определение типа кабеля (прямой/перекрестный)

    interface GigabitEthernet 0/0 - Настройка порта маршрутизатора (L3)
        ip address [IP] [Маска]    - Назначение IP-адреса
        no shutdown                - Включение порта

    interface vlan 99            - Переход к настройке виртуального интерфейса (SVI)
        ip addres [IP] [Маска] 
        no shutdown 
        description Management Interface

    [ Полезные утилиты и модификаторы ]
    terminal history size 200    - Увеличивает буфер памяти команд (до 256)
    show history                 - Выводит список введенных команд

    Модификаторы вывода (через знак |):
    | section                  - Выводит только определенный блок конфигурации
    | include                  - Выводит только строки, содержащие искомое слово (аналог grep)
    | exclude                  - Исключает строки с искомым словом (аналог grep -v)
    | begin                    - Выводит весь текст, начиная с первого совпадения

    ! 1. Создаем нужные VLAN и даем им понятные имена (опционально, но полезно)
    vlan 10
        name Managers
    exit
    
    vlan 20
        name Guests
    exit

    ! 2. Настройка одного порта (например, для ПК менеджера)
    interface FastEthernet 0/1
        switchport mode access        ! Указываем, что порт смотрит на конечное устройство
        switchport access vlan 10     ! Помещаем порт в VLAN 10
    exit

    ! 3. Настройка сразу нескольких портов одновременно (диапазон)
    interface range FastEthernet 0/2 - 10
        switchport mode access
        switchport access vlan 20     ! Помещаем порты со 2 по 10 в VLAN 20
    exit
