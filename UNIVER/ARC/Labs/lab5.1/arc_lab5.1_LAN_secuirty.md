**Distributed Denial of Service** (*DDoS)* - атака от одной (***DoS***) или нескольких машин которая имеет как цель временно отключить доступ к ресурсу.

**Data breach** - это инцидент кибербезопасности, при котором злоумышленники получают несанкционированный доступ к конфиденциальной информации на скомпрометированных серверах, хостах или в базах данных.

**Malware** - программа которая имеет как цель заразить пк для дальнейшей эксплоатации со стороны атакуюшего.
- **Spyware** - для слежки 
- **Adware** - для спама реклам
- **Backdoor** - для создания доп.точки входа 
- **Ransomware** - для блокировки пк
- **Scareware** - для того чтобы напугать пользователя
- **Rootkit** - для получение привилегии в системе и сокрытие своего присутсвия в системе
- **Virus** - для заражения файлов
- **Trojan** - маскируется под полезную программу
- **Worms** - вирус который сам саморазмножения и распространения по пк и по сети без присутвия атакующего

### Network Security Devices

**VPN-Enabled Router** - для создания защищенных и зашифрованных каналов связи между удалёным пк и сетью. 

**NGFW** (*Next-Generation Firewall*) - для глубокой инспекции сетевого трафика, фильтрации на уровне приложений, предотвращения вторжений (***IPS***) и блокировки комплексных угроз (в отличие от классических межсетевых экранов). В отличие от обычного фаервола (3-4 layers), **NGFW** работает на всех 7 уровнях OSI.
	**IPS** *(Intrusion Prevention System)* - это система предотвращения вторжений. Представляет собой программно-аппаратный комплекс (или модуль в составе ***NGFW***), который в реальном времени анализирует сетевой трафик для поиска и автоматической блокировки потенциальных атак и угроз

**NAC** *(Network access)* - целая архитектура для защиты от несканцианированных устройст которые подключились локально к сети

**ESA** *(EMAIL Security Appliance)* - девайс который мониторит сообщения приходящие по SMTP.

**WSA** *(Web Security Appliance)* - девайс который мониторит сообщения приходящие по HTTP.

### **Layer 2 Attack**

- **MAC Table Attacks (MAC Flooding) -** атака которая имеет цель заполнить MAC таблицу цели. Когда у свича переполняется таблица он перестает фильтровать трафик и работает как хаб.
- **VLAN Attacks (VLAN Hopping) -** обход сегментации сети для доступа к трафику других VLAN.
		* **Switch Spoofing** - использование протокола **DTP** для принудительного перевода порта в транковый режим.  
		* **Double Tagging** -  внедрение второго **802.1Q** чтобы коммутатор снял первый тег и перенаправил кадр в целевую VLAN. 
		* ***Защита: Отключить DTP, использование Native VLAN 999***
- **DHCP Attacks -** делятся на:
		* **DHCP Starvation** - отправка тысяч запросов с поддельными MAC адресами для исчерпания пула доступных IP адресов 
		* **DHCP Spoofing** - установка **Rogue DHCP** который выдает жертвам IP адрес атакующего в качестве шлюза по умолчанию или DNS
		* ***Защита: DHCP Snooping***
- **ARP Attacks -** атакующий рассылает поодельные **ARP** сообщения в локалке связывай свой MAC адрес с IP адресом легитимного узла.
	    * ***Защита: Dynamic ARP Inspectation***
- **Address Spoofing Attacks -** Умышленная подмена IP-адреса или MAC-адреса отправителя в пакетах. Используется для обхода списков контроля доступа (ACL), фильтров безопасности или для маскировки под доверенный сервер/хост внутри сети.
	    * ***Защита: IP Source Guard (IPSG).***
- **STP Attacks -** вмешательство в работу STP. Атакующий генерирует поддельные кадры **BPDU** с приоритетом превосходящим текущий, чтобы заставить сеть выбрать его устройство в качестве корневого моста. Это перестраивает логическую топологию сети и пускает трафик через узел злоумышленника. 
	    * ***Защита: BPDU Guard и Root Guard***

### **Layer 2 Defence**

**Port security -** Жестко ограничивает количество уникальных MAC-адресов, которые могут быть подключены к конкретному физическому порту коммутатора, либо привязывает к порту строго определенные MAC-адреса

**DHCP Snooping -** Превращает коммутатор в "строгого цензора" для DHCP-трафика. Администратор делит порты на _Trusted_ (куда разрешено подключать легитимные DHCP-серверы) и _Untrusted_ (обычные пользовательские розетки

**DAI (Dynamic ARP Inspectation) -** Проверяет подлинность ARP-пакетов (запросов и ответов). Для этого технология опирается на базу данных **DHCP Snooping Binding Table**, где записано, какому порту какой IP- и MAC-адрес был выдан легитимно. Если кто-то шлет ARP-ответ с чужими данными, коммутатор его уничтожает

**IP Source Guard (IPSG) -** Фильтрует трафик на уровне IP, используя ту же привязку из DHCP Snooping (а также статические IP-биндинги). Коммутатор сверяет IP- и MAC-адрес в заголовке каждого проходящего пакета с таблицей разрешений для данного порта
