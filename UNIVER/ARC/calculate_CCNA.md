
Подсчет маски:
   Дано: 60 адресов

   Нужно найти 2^K которое больше 60
	2^6 = 64 => 1000000, добавляем 1 слева => 11000000 => 128+64 = 192
   будет 255.255.255.192
   
   Новый префикс = старый префик + k = 0/24 + 6 = 0/30
   выходит что 192.168.1.0/30 -> 255.255.255.192

Подсчет префика:
   Всего в сети 32, выходит 32 - k -> 32 - 6 = 26


Подсчет Vlan

   Например даны 10 vlan: N = 10
   
   Формула:
     2^k >= N
     2^4 = 16 >= 10
   
   Префикс:
     0/24 + 4 = 0/28 -> 4 (k) единицы слева -> 11110000

     128 + 64 + 32 + 16 = 240 -> 255.255.255.240 или 192.168.1.0/28
   
   Vlan:
     У нас 16 адресов, где 3 заняты по дефолту: выходит 13 свободных адресов
   
   Vlan 10:
      Адрес: 192.168.1.0/28
      Gateway: 192.168.1.1 
      Доступно: 13 => .2 - .14 (где .0, .1, .15 заняты)
   
   Vlan 20:
      Адрес: 192.168.1.16/28
      Gateway: 192.168.1.17
      Доступно: 13 => .18 - .30
