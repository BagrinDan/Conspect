


Terraform - инструмент Iac, который помогает автоматизировать соборку серверов и за счет этого защищает от случайных поломок
    > terraform init - 
    > terraform plan - показывает что скрипт будет делать
    > terraform apply - выполнения плана
    > terraform destroy - удаления всех ресурсов

    STATE:
    > terraform import - импорт сущесвтующих ресурсов
    > terraform state line - список всех ресурсов
    > terraform state show <res_name>
    > terraform refresh - 
    > terraform validate
    > terraform fmt
