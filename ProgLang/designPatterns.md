


    - Пораждающие
        > Фабрика - паттерн который определяет интефрейс и делегирует создания объектов подклассам
            [*] Причина: когда нужно создавать объекты не нарушаея OCP
            ['] Пример: создания пиццы, кофе, пк...

        > Абстрактная Фабрика - это порождающий паттерн, который решает задачу создания семейств 
            связанных или зависимых объектов, не привязываясь к их конкретным классам
            [*] Причина: когда нужно создавать семейство объектов 
            ['] Пример: создания пиццы с определнными компонентами, пк с разными комплектующими, 
            заказ с определнным типом упоковки

        > Билдер - паттерн который позволяет собирает класс у которых много атрибутов
            [*] Причина: у объекта много атрибутов
            ['] Пример: Заказ с множественными полями и разными комбинациями его инициализации и создания
            [!] Особенности: реализация с Директором и без

        > Прототип - паттерн который позволяет экономить на создания объектов (!!!!!!!!)
            [*] Причина: объекта нужно вызвать десятки разными
            ['] Пример: монстры в играх
            [!] Особенности: есть два типа реализации: Deep Copy/ Swallow Copy

        > Синглтон - паттерн который определяет класс уникальным и единствинным на всю систему и делает
            его глобальной точкой
            [*] Причина: нужен 1 объект к которому будут обращаться все остальные объекты
            ['] Пример: Логгер, Warehouse, Cклад
