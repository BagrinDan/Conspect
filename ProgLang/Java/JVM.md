
Pipeline: 

    =====================================
    -------------- IDE ------------------
    =====================================

        Создает файл .java. В него мы записывает код:
            System.out.print("Hello");
        Java готовит в папке out все классы для отправки компилятору 

    =====================================
    -------------- JDT ------------------
    =====================================

        Внутри файал .java передается компилятору который превращает его в байт код
        и меняет тип на .class. После передается утилите java.

    =====================================
    -------------- JRE ------------------
    =====================================

    Дальше файл выгру


    


    > JDK (java developer kit) - это комплект инструментов, библиотек и исполняемых файлов, необходимых для разработки Java-приложений.
    Внутри него входит 
        - JRE,
        - JDT.

    > JDT - это набор утилит и инструментов, поставляемых в составе JDK, 
    которые необходимы разработчику для создания, компиляции, отладки и анализа Java-приложений.

    > JRE (Java runtime enviroment) - среда которая запускает код
    Внутри JRE:
        - JVM,
        - Java Class Library
        - Config files

    > JVM (Java Virtual Machine) - это сред которая выполняет байт код
    Внутри JVM:
        - Class loader - механизи доставки который отвечает за их загрузку в память
        - Runtime Data Areas: 
            > Stack
            > Heap
            > Method Area:
                > Constant pool - это место где компилятор собирает все литералы (строки, числа, имена методов, названия классов).
                Живет в .class.
        - Execution Engine:
            > Garbage Collector (GC)
            > JIT (just in time)
