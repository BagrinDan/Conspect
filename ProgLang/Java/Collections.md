        ---- Lists ----

          > ArrayList:
            * List.of(A) - создает новый вложенный список на основе другого списка или вложенных элементов
            * List.of(A.toArray()) - 
            * List.copyOf(A) - создает новый отдельный и независимый список на основе списка А   

            * get(i) = O(1)
            * contains(x) = O(n)
            * встака/ удаления [начало, середина, конец] = [ O(n) / O(n) / O(1)(амортизация)]

            [*] ArrayList использует динамический массив. Поиск по индексу быстрый, но вставка в начало/середину требует сдвига всех элементов $O(n)$. 
            При переполнении массива происходят выделение новой памяти и копирование (O(n) амортизированное).

          > LinkedList:
            * get(i) = O(n)
            * contains(x) = O(n)
            * встака/ удаления [начало, середина, конец] = [ O(1) / O(n) / O(1)]

            [*] LinkedList — двусвязный список. Операция вставки/удаления $O(1)$, только если у вас уже есть ссылка на этот узел (например, через ListIterator). 
            Если узел нужно сначала найти — операция займет $O(n)$.

        ---- Set ----

          > HashSet:
            * contains/ add / remove = O(1)
            * Не гарантирует последовательность элементов и не сохраняет одинаковые значения

            [*] HashSet использует хэш-таблицу. Если в одном бакете несколько хешей, то сложность может возрасти до O(log(n)) 
            образуя вложенный список. Если данный список становится слишком большим, то он трансформируется в Красно-Черное дерево.
          
          > LinkedHashSet:
            * contains/ add / remove = O(1)
            * Гарантирует последовательость элементов

            [*] LinkedHashSet дополнительно поддерживает двусвязный список поверх хэш-таблицы для сохранения порядка итерации.

          > TreeSet:
            * contains/ add / remove = O(log (n))
            * Отсортирован (Red-Black tree)

            [*] TreeSet основан на TreeMap (Красно-черное дерево). Поддерживает элементы в отсортированном виде.

        ---- Map ----

          > HashMap:
            * contains/ add / remove = O(1)
            * Не гарантирует последовательность элементов и не сохраняет одинаковые значения

          > LinkedHashMap:
            * contains/ add / remove = O(1)
            * Гарантирует последовательость элементов
          > TreeMap:
            * contains/ add / remove = O(log (n))
            * Отсортирован (Red-Black tree)
