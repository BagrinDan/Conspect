

    > IoC (Inversion of Control) - идея при котором фреймворк управляет жизненым циклом объектов, 
    Спринг берет на себя всем жизненын циклом приложения

    > DI (Dependency Injection) - способ инжектировать объекты в класс. Есть 3 вида DI:
        - Field Injection - способ инжектить значение в поле. Spring делает это через Java Reflection
        - Constructor; 
        - Setter;

    > Бин - это инстэнс класса за жизненым циклом которым управляет Спринг

    > @Bean - это инструкция на метод который позволяет превратить возвращаемый класс в Синглтон.

    > @Scope - это инструкция на метод который позволяет управлять жизненым циклом возвращаемого класса. 
    Чаще используется чтобы сделать его не синглом
