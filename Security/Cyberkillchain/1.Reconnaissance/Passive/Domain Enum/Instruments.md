## *dnsrecon*

***dnsrecon** - утилита для сбора информации о всей инфраструктуре цель о домене цели*
*используя DNS запросы.*
#### **Базовый синтаксис:** 
`dnsrecon -d [target domain] [flags]`
##### **Примеры команд:**
`dnsrecon -d cisco.com` - сбор всех типов записей о домене `cisco.com`

[ ! ]**без типа ***dnsrecon* отправляет все виды DNS запросов с целью о получении информации

## *nslookup*

***nslookup** - это разведка по площадям (собрать **всё**, что связано с доменом, выявить скрытую инфраструктуру).*

#### **Базовый синтаксис:** 
`nslookup [target] [optional_dns_resolver]`
##### **Примеры команд:**
`set type=ns` - для получения DNS серверов
`set type=any` - отправляем все виды DNS запросов: A, AAAA, MX, NS, TXT, SOA, CNAME

`nslookup netacad.com 8.8.8.8 `- сканируем веб ресурсы `netacad.com` и принудительно указываем как dns сервер `8.8.8.8`

[ ! ]**без типа *nslookup* отправляет запрос *А* и *AAAA* с получением айпи Веб ресурса**

## *dig* 

***dig** - это разведка по площадям (собрать **всё**, что связано с доменом, выявить скрытую инфраструктуру).*
#### **Базовый синтаксис:** 
`dig @[dns_resolver] [target] [type]`
##### **Примеры команд:**
`dig @8.8.8.8 cisco.com ns` - отправить `ns` на `cisco.md` используя как dns resolver `8.8.8.8`

[ ! ]**без типа dig отправляет только запрос *A* с получением айпи веб ресурса**
