асть 1. tcpdump (Швейцарский нож для сетевого анализа)

tcpdump — это консольный сниффер пакетов. Он работает везде (на серверах в Azure, роутерах, Linux-хостах) и незаменим, когда нужно понять, доходят ли пакеты до сервера.
1. Основные флаги управления

    -i <interface> — выбрать сетевой интерфейс для прослушивания (например, -i eth0 или -i wlan0). Напиши -i any, чтобы слушать вообще все интерфейсы.

    -n — не разрешать IP-адреса в доменные имена (ускоряет работу и не спамит DNS-запросами).

    -nn — не разрешать ни IP-адреса, ни номера портов (покажет 80 вместо http, 22 вместо ssh).

    -v, -vv, -vvv — уровень детализации вывода пакетов (чем больше v, тем подробнее расписываются заголовки).

    -c <number> — перехватить ровно указанное количество пакетов и завершить работу.

    -X — вывести содержимое пакета и в Hex (шестнадцатеричном формате), и в ASCII (текстом). Отлично подходит, чтобы ловить тот самый незашифрованный трафик вроде Telnet или HTTP.

2. Сохранение и чтение (Работа с .pcap)

    -w <file.pcap> — записывать весь перехваченный трафик в файл. Этот файл потом можно открыть в Wireshark и красиво проанализировать графически.

    -r <file.pcap> — прочитать и вывести на экран ранее сохраненный файл.

3. Фильтры (Самая мощная часть tcpdump)

Флаги можно комбинировать с помощью логических операторов and, or, not.

    host 192.168.1.8 — ловить пакеты только для/от конкретного IP.

    src 192.168.1.5 — только исходящие пакеты с этого IP (Source).

    dst 192.168.1.20 — только входящие пакеты на этот IP (Destination).

    port 80 — фильтровать только по конкретному порту.

    tcp или udp, icmp — фильтрация по протоколу.
