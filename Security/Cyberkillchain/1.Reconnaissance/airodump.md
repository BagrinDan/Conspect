Часть 2. airodump-ng (Разведка беспроводных сетей)

airodump-ng входит в состав пакета aircrack-ng. Он используется для сканирования радиоэфира, поиска Wi-Fi точек доступа (BSSID), поиска подключенных к ним клиентов (STATION) и захвата «хендшейков» (Handshakes) для последующего аудита паролей.

    ⚠️ Важно: Перед запуском airodump-ng твоя Wi-Fi карта должна быть переведена в режим мониторинга (Monitor Mode) с помощью команды sudo airmon-ng start wlan0.

1. Основные флаги

    --band <abg> — указать частотный диапазон. По умолчанию сканирует 2.4 GHz (g). Если у тебя двухдиапазонная карта и нужны сети 5 GHz, пиши --band a.

    -c <channel> — жестко зафиксировать конкретный Wi-Fi канал (например, -c 6). Без этого флага утилита постоянно прыгает по каналам, из-за чего можно упустить важные пакеты.

    --bssid <MAC-адрес> — фильтровать вывод и собирать пакеты только от одной конкретной точки доступа.

    -w <prefix> — имя файла для сохранения перехваченных данных (запишет файлы с расширениями .cap, .csv и др.). Именно в .cap файл падает пойманный хендшейк.

    --essid <Name> — фильтровать точки доступа по их текстовому имени (SSID).
