
Command and Control - 


Атакующий

- Установление связи (Beaconing) с C2-сервером
- Зашифрованный туннель команд (DNS/HTTPS)
- Передача инструкций для дальнейших действий


Защитник (Mitigation)

- DNS-фильтрация и Sinkholing C2-доменов
- Блокировка нетипичных исходящих соединений
