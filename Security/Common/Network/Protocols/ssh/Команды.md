## **Подключение**

**Синтаксис:**
* `ssh [hostname]@[host_ip]` - войти по логину и паролю
* `ssh -i [private_key] [hostname]@[host_ip]` - войти через ключ

**Пример:**
* `ssh user@192.168.1.1` - базовое подключение по ssh
* `ssh -i .ssh/id_ed25519_privatus user@192.168.1.1` - подключение по ssh используя приватный ключ

-----------------

## **Отправка/Получение**

*Используются: **SCP, Rsync, SFTP***

### **SCP**
***scp** - старый протокол для отправки и скачивания*

**Синтаксис:**
* `scp [hostname]@[host_ip]:/path/get/file.txt /path/put/file.txt` - скачать
* `scp /path/to/file.txt [hostname]@[host_ip]:/path/where/to/put/` - отправить

**Пример:**
* `scp user@192.168.1.1:/home/user/abobus.txt /home/client/` - скачать
* `scp /home/client/abobus.txt user@192.168.1.1:/home/user/` - отправить

------------------
### **Rsync** 
***Rsync** - нужен для умного скачивания. Он может сравнить изменёный файл и скачать только остаток.*

* `rsync -avz admin@192.168.1.1:/var/log/nginx/ /home/client/downloaded_logs/` - скачать 
* `rsync -avz /home/client/my_project/ admin@192.168.1.1:/home/admin/backup_project/` - отправить

--------------------
### **SFTP**
**SFTP** - протокол для удобной отправки и скачивания 

* `sftp> put /home/client/report.pdf` - отправить
* `sftp> get /home/client/report.pdf` - скачать
