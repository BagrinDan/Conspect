**SSL (Secure Socket Layer) -** технология которая позволяет вести заштфрововонное общение между клиентом и сервером. 

**TLS (Transport Layer Security)** - улучшеная версия SSL, которая безопастнее, быстрее и надежнее.

**SSL/TLS handshake:**
1. **Client Hello**: Клиент отправляет сервер список поддерживаемых версии протокола (*TLS 1.1,  TLS 1.2*), список поддерживаемых криптографических алгоритмов (*Cipher Suites*) и случайную строку байтов - `Client Random`
2. **Server Hello** **& Certificate**: Сервер выбираем найболее надежный алгоритм из предложенных клиентом. Затем отправляет `Server Random`и свой SSL-сертификат. Данный сертификат содержит публичный ключ (*Public Key*) и цифровую подпись удостоверяющего центра (*CA*)
3. **Authentication:** Клиент проверяет сертификат на предмет истичения срока, совпадение домена и доверяет ли ОС или браузер удостоверяющему центру, выдавшему этот сертификат.
4. **Key Exchange:** Если сертификат валиден, Клиент генерирует новый секрет `Pre-Master Secret`. Клиент шифрует его публичным ключом сервера и отправляет на сервер. 
5. **Генерация Session key:** Теперь у обеих сторон на руках есть три элемента: `Client Random`, `Server Random` и `Pre-Master Secret`. Используя согласованный алгоритм, обе стороны локально генерируют из этих данных один и тот же **симметричный сессионный ключ (Session Key)**
6. **Finished:** Обе стороны отправляют друг другу тестовое зашифрованное сообщение ("Finished"), подтверждая, что ключи совпадают и рукопожатие успешно завершено. Начиная с этого момента весь HTTPS-трафик шифруется сгенерированным симметричным ключом.
