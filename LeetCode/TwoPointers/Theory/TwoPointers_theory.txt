

    Есть 3 типа:   
        ================
        > С двух сторон:
        ================ 
            - Ставятся два указателя, один в начало - другой в конце.

            > Паттерн:
                int left = 0;
                int right = array.length - 1;

                while(left < right){
                    ...
                }
        
        =======================
        > Каждому по указателю:
        =======================
            - По одному указателю на каждый массив

            > Паттерн:
                int p1 = 0;
                int p2 = 0;
                int[] result = new int[];

                while(p1 < nums1.length && p2 < nums2.length){
                    ...
                }

        ======================
        > Быстрый и медленный:
        ======================
            - Ставястя два указателя в начало, где первый медленный двигается по условию а быстрый всегда

            > Паттерн:
                int slow = 0;
                int fast = 0;

                while(fast < nums1.length){
                    ...
                }
