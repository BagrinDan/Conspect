`su` - войти как рут
`su [username]` - войти как другой пользователь

----------------
`ls -l [тип/права] [владелец] [группа] [размер] [дата] [имя]`
`id` -  увидеть информацию о текущем пользователе

`sudo chown [user] [file]` - поменять владельца файла
`sudo chgrp [group] [file]` - поменят группу файла
`sudo chmod [опции] [file]`
	- `u+r` - пользователь получает возможность читать файл
	- `g+wx`
	- `o-w` - забирает у остальных писать файл
	- `a-rwx` - забирает у всех возможность делать что либо с файлом

`sudo chmod u+s [file]`
`sudo chmod 4777 [file]` - установка SUID
