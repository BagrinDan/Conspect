Redis - in-memory хранилище данных. Хранения данных происходит в виде ключа [key]
и значения [value]. 

Приминения: База данных, Кэш, Брокер Сообщении

Redis делится на две части: redis-cli/iredis и redis server

В Редис всё строки и списки. Если положить число, то в Редисе он будет как строка

Редис работает от оперативки, но сохраняет значения на жестком диске

TTL - время жизни ключа
    1) -1 => без TTL
    2) -2 => ключа нет
    3) 60 => например 60 секунд 

==================
Синтаксис
=================

[****СТРОКИ****]

    Запуск: [redis-cli]. Или [redis-cli -h {IP} -p {PORT}]

    * )SET - установить значения. Часто используется с числом, например car:1, session:2
        Доп опции: nx/xx - добавить если нет/если есть

    *) MSET - записать несколько ключей сразу
    Пример: MSET name Ivan age 20 city Chisinau

    *) MGET - вывести сразу несколько ключей сразу в виде МАССИВА ЗНАЧЕНИИ
    Пример: MGET name age city

    *) GET - вывести значение. ЕСЛИ значения нет, то будет выведенно (nil)

    *) GETSET - выводит старое значение и заменяет на новое
    Пример: GETSET [ключ] [значение]

    *) DEL - удалить значение
    *) INCRYBY/DECRBY - инкременит/дикременит число на определённое.
    Пример: INCRYBY counter 5

    *) INCR/DECR - инкремент/дикременит число на 1. ПОТОКО-БЕЗОПАСЕН
    Пример: INCR counter

    *) KEYS * - вывести всё. ОДНОПОТОЧНЫЙ
    *) SCAN 0 - вывести всё. МНОГОПОТОЧНЫЙ


[****СПИСКИ****]
    [**CRUD**]
        *) LPUSH/RPUSH - положить элмент вначале/в конце списка


    [**GENERIC**]
        *) LRANGE 0 -1 - длинна списка ВКЛЮЧИТЕЛЬНО. 0 это первый, -1 это последний
        *) LPOP/RPOP - вывести и удалить первый/последний значения 
        *) LLEN - длинна списка

        *) LMOVE - переместить (не копирует) одно значения из списка в другое  
        Пример: LMOVE {first list} {second list} LEFT LEFT ->
        LMOVE - list move, LEFT LEFT это откуда взять значения из каждого списка



===================
== [ХЭШ-таблица] ==
===================
    
    [""CRUD""]

    > CREATE/UPDATE:
        *) HSET - создать или добавить значение в хэш-таблица
        Пример: HSET {ключ} {поле} {значение}

    > READ:
        *) HGET - получить ОДНО значение из таблицы. 
        Пример: HGET {названия таблицы} {атрибут}

        *) HGETALL - получить все значения из ключа
        Пример: HGETALL {ключ}

        *) HMGET - получить НЕСКОЛЬКО значении из таблицы
        
        *) HKEYS/HVALS - получить только ключи/значения

    > DELETE:
        *) DEL/UNLINK - удалить ключ. DEL блокирует поток,
        а UNLINK удаляет в фоновом потоке 
        Пример: DEL {ключ}, UNLINK {ключ}

        *) HDEL - удалить определнное поле из ключа
        Пример: HDEL {ключ} {поле}

    [**GENERIC**]
    *)HINCRYBY - инкременить значение таблицы


=======
=[СЕТ]=
=======
    [**CRUD**]
        > CREATE
            *) SADD [key] [member] - добавить элемент в множество
        > READ
            *) SMEMBERS user:1:tags
        > UPDATE
            *) SMOVE tags:active tags:archived "old_tag"
        > DELETE
            *) SREM (set remove)- удалить

    [**GENERIC**]
        *) SISMEMBER (Set is member) - проверяет наличие элемента 
        *) SCARD - возвращает размер

=[SORTED SET]=
==============

    [**CRUD**]
        > CREATE / UPDATE
            *) ZADD [key] [score] [value]
        Пример: ZADD game:1001 2 "Andrei" 1 "Ivan" 3 "Igori" 
        > READ
            *) ZRANGE game:1001 0 -1 WITHSCORES
        > DELETE
            *) ZREM 

    [**GENERIC**]




[ОБЩЕЕ]

    TTL - получить время жизни ключа

    EXPIRE - установить время жизни клюача
    Пример: EXPIRE {ключ} {время}
    
    EXIST - проверить если существует ключ

    SETEX - создать ключ с TTL
    Пример: SETEX {ключ} {TTL} {значение}
